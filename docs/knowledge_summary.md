# 知识点总结

## 一、多任务学习基础

### 1.1 多任务学习 (MTL) 概念

**定义**：同时学习多个相关任务，共享知识以提高泛化能力。

**核心假设**：相关任务之间存在共享的知识，可以相互促进。

**数学形式**：
$$\min_{\theta} \sum_{t=1}^{T} \lambda_t L_t(f_{\theta_t}(x), y_t)$$

其中：
- $T$ 是任务数量
- $\lambda_t$ 是任务权重
- $L_t$ 是任务损失
- $\theta_t$ 是任务参数（可能包含共享部分）

### 1.2 多任务学习的挑战

| 挑战 | 描述 | 解决方案 |
|------|------|----------|
| 负迁移 | 任务间相互干扰 | 任务解耦 (PLE) |
| 梯度冲突 | 梯度方向相反 | PCGrad |
| 任务主导 | 某任务主导训练 | 动态权重调整 |
| 数据不平衡 | 各任务数据量差异 | 采样策略 |

### 1.3 常见多任务架构

```
1. Hard Parameter Sharing (硬共享)
   ┌─────────────┐
   │  共享层     │
   └──────┬──────┘
      ┌───┴───┐
      ↓       ↓
   任务A    任务B

2. Soft Parameter Sharing (软共享)
   ┌─────┐   ┌─────┐
   │任务A│   │任务B│
   └──┬──┘   └──┬──┘
      └───┬───┘
         共享约束

3. MoE (Mixture of Experts)
   ┌───┐ ┌───┐ ┌───┐ ┌───┐
   │E1 │ │E2 │ │E3 │ │E4 │
   └─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘
     └─────┴─────┴─────┘
            ↓
        Gate网络

4. PLE (Progressive Layered Extraction)
   ┌───────┐ ┌───────┐
   │共享专家│ │任务专家│
   └───┬───┘ └───┬───┘
       └─────┬─────┘
             ↓
         Gate网络
```

## 二、PLE 架构详解

### 2.1 PLE vs MMoE

| 特性 | MMoE | PLE |
|------|------|-----|
| 专家类型 | 全部共享 | 共享 + 任务特定 |
| 任务干扰 | 存在 | 减少 |
| 可解释性 | 一般 | 更好 |
| 参数效率 | 高 | 中 |

### 2.2 PLE 核心组件

**1. 共享专家 (Shared Experts)**
- 学习跨任务的通用知识
- 所有任务共享参数
- 数量通常较少 (2-4个)

**2. 任务特定专家 (Task-specific Experts)**
- 学习任务独有的知识
- 每个任务有独立的专家
- 避免任务间干扰

**3. 门控网络 (Gate Network)**
- 动态选择专家组合
- 输出专家权重分布
- 可添加稀疏度约束

### 2.3 门控网络设计

**Softmax Gate:**
$$g = \text{softmax}(W^T x)$$

**Top-K Gate:**
$$g_k = \begin{cases} \frac{\exp(s_k)}{\sum_{j \in TopK} \exp(s_j)} & k \in TopK \\ 0 & \text{otherwise} \end{cases}$$

**带温度的 Gate:**
$$g = \text{softmax}(W^T x / \tau)$$

温度 $\tau$ 的作用：
- $\tau > 1$：分布更平滑，探索更多
- $\tau < 1$：分布更尖锐，利用更强

### 2.4 稀疏度约束

**熵最小化:**
$$L_{sparsity} = H(g) = -\sum_k g_k \log g_k$$

**目的**：鼓励门控权重集中，提高可解释性

## 三、梯度冲突与 PCGrad

### 3.1 梯度冲突的数学定义

设任务 $i$ 和 $j$ 的梯度为 $g_i$ 和 $g_j$：

**余弦相似度:**
$$\cos(g_i, g_j) = \frac{g_i^T g_j}{\|g_i\| \|g_j\|}$$

**冲突条件:**
$$\cos(g_i, g_j) < 0$$

### 3.2 PCGrad 算法流程

```
输入: 任务梯度 {g_1, g_2, ..., g_T}

for each task i:
    for each task j ≠ i:
        if cos(g_i, g_j) < 0:
            # 投影 g_i 到 g_j 的法平面
            g_i = g_i - (g_i · g_j) / ||g_j||² * g_j

输出: 投影后的梯度 {g'_1, g'_2, ..., g'_T}
```

### 3.3 PCGrad 的几何解释

```
原始情况 (冲突):
         g_i
          ↖
           \
            \  冲突区域
             \
    ←---------●--------→ g_j
              P

投影后:
         g_i^proj
             ↑
             |
             |  正交
             |
    ←---------●--------→ g_j
              P

g_i^proj = g_i - proj_{g_j}(g_i)
         = g_i - (g_i · g_j / ||g_j||²) * g_j
```

### 3.4 PCGrad 的优势

| 优势 | 说明 |
|------|------|
| 无需修改模型 | 只修改梯度计算方式 |
| 理论保证 | 保证投影后梯度不冲突 |
| 通用性强 | 适用于任意多任务模型 |
| 计算开销小 | 只需额外的点积运算 |

## 四、损失函数设计

### 4.1 Focal Loss

**问题**：类别不平衡导致模型偏向多数类

**解决方案**：降低易分类样本的权重

**公式推导:**

标准交叉熵:
$$CE(p, y) = -y\log(p) - (1-y)\log(1-p)$$

定义 $p_t$:
$$p_t = \begin{cases} p & y=1 \\ 1-p & y=0 \end{cases}$$

简化:
$$CE(p_t) = -\log(p_t)$$

Focal Loss:
$$FL(p_t) = -\alpha_t(1-p_t)^\gamma \log(p_t)$$

**参数说明:**
- $\alpha_t$: 类别权重，平衡正负样本
- $\gamma$: 聚焦参数，降低易分类样本权重
  - $\gamma=0$: 退化为标准交叉熵
  - $\gamma=2$: 常用设置

### 4.2 难负例挖掘

**问题**：简单负样本对模型学习贡献小

**策略**：选择损失最大的负样本

**算法:**
```
1. 计算所有负样本的损失
2. 按损失降序排序
3. 选择前 k% 的负样本
4. 与正样本一起计算损失
```

### 4.3 R-Drop 正则化

**思想**：同一样本的两次预测应该一致

**实现:**
```
1. 对同一样本进行两次前向传播（不同 Dropout）
2. 计算两次预测的 KL 散度
3. 将 KL 散度作为正则化项
```

**公式:**
$$L_{R-Drop} = \frac{1}{2}(KL(p_1 \| p_2) + KL(p_2 \| p_1))$$

## 五、正则化技术

### 5.1 Dropout 变体

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| Dropout | 随机丢弃神经元 | 全连接层 |
| DropConnect | 随机丢弃连接权重 | 全连接层 |
| DropBlock | 随机丢弃连续区域 | 卷积层 |
| Spatial Dropout | 随机丢弃整个通道 | 卷积层 |

### 5.2 DropBlock 详解

**动机**：卷积特征图有空间相关性，单点丢弃效果有限

**方法**：丢弃连续的区域

**参数:**
- block_size: 丢弃区域大小
- drop_prob: 丢弃概率

**公式:**
$$\gamma = \frac{drop\_prob}{block\_size^2}$$

### 5.3 Label Smoothing

**问题**：模型过度自信，过拟合

**方法**：软化标签

**公式:**
$$y_{smooth} = y(1-\epsilon) + \frac{\epsilon}{K}$$

其中 $K$ 是类别数，$\epsilon$ 是平滑系数

**效果:**
- 防止模型输出极端概率
- 提高模型泛化能力
- 减少过拟合

## 六、评估指标

### 6.1 分类指标

**AUC (Area Under ROC Curve):**
- 衡量排序能力
- 与阈值无关
- 范围 [0.5, 1.0]

**LogLoss:**
- 衡量概率校准
- 对预测概率敏感
- 越小越好

### 6.2 排序指标

**NDCG (Normalized DCG):**
$$DCG@K = \sum_{i=1}^{K} \frac{2^{rel_i} - 1}{\log_2(i+1)}$$

$$NDCG@K = \frac{DCG@K}{IDCG@K}$$

**特点:**
- 考虑位置信息
- 前面的位置权重更高
- 归一化到 [0, 1]

**Hit Rate:**
$$HR@K = \frac{\text{命中数}}{\text{总用户数}}$$

**特点:**
- 简单直观
- 只关心是否命中
- 不考虑排序位置

## 七、训练技巧

### 7.1 学习率调度

**常见策略:**

| 策略 | 公式 | 特点 |
|------|------|------|
| Step Decay | $\eta_t = \eta_0 \cdot \gamma^{\lfloor t/T \rfloor}$ | 周期性下降 |
| Exponential Decay | $\eta_t = \eta_0 \cdot \gamma^t$ | 指数下降 |
| Cosine Annealing | $\eta_t = \eta_{min} + \frac{1}{2}(\eta_0 - \eta_{min})(1 + \cos(\frac{t}{T}\pi))$ | 平滑下降 |
| Warmup | $\eta_t = \eta_0 \cdot \frac{t}{T_{warmup}}$ | 预热阶段 |

### 7.2 梯度裁剪

**目的**：防止梯度爆炸

**方法:**
```python
# 按范数裁剪
torch.nn.utils.clip_grad_norm_(parameters, max_norm)

# 按值裁剪
torch.nn.utils.clip_grad_value_(parameters, clip_value)
```

### 7.3 Early Stopping

**策略:**
```
1. 监控验证集指标
2. 如果连续 patience 个 epoch 不改善
3. 停止训练，恢复最佳模型
```

**参数:**
- patience: 容忍次数
- min_delta: 最小改善阈值
- mode: 'min' 或 'max'

### 9.1 过拟合处理

| 方法 | 说明 |
|------|------|
| 数据增强 | 增加数据多样性 |

| 方法 | 说明 |
|------|------|
| 增加模型复杂度 | 更多层、更多参数 |
| 减少正则化 | 降低权重衰减 |
| 增加训练时间 | 更多 epoch |
| 特征工程 | 添加更多特征 |
| 调整学习率 | 可能学习率过小 |
